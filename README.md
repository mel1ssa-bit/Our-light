# Bloom Maze

Cacto redondo que espalha agua num labirinto rosa. Por onde passa, o jardim cresce (meta 70%). Fantasminhas secam o rastro. Tunel secreto com vasinho CBD.

## Arquivos

- `index.html` — pagina
- `style.css` — visual
- `game.js` — logica (tilemap, %, pathfinding)
- `README.md` — este arquivo

## Jogar

Abra `index.html` no navegador.

## Controles

Setas ou WASD. No mobile: D-pad ou swipe.
